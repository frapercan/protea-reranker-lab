## Schema

Each row is one (query protein, retrieved GO term) candidate produced
by the K nearest neighbour retrieval against the PLM embedding pool.
The label is binary (annotation appeared in the eval lineage delta).

Top level column families (see schema sha `6d97a624b8a7` for the
exact canonical list):

* identifiers: `protein_id`, `go_term`, `aspect`, `eval_snapshot_pair`
* retrieval: KNN distances, retrieval ranks, lineage scores
* alignment: pair feature align statistics (when produced)
* taxonomy: lineage agreement features
* embeddings: anc2vec GO term features (200 dim) plus optional
  PCA(16) of the PLM mean pool, see caveats
* labels: binary annotation outcome

Total features is fixed across the bench-v1-K{3,5,10}-v226-lineage
family for a given `schema_sha`. Datasets ship with PCA(16)
unconditionally; the PCA basis is fit per PLM on the full
(train + eval) embedding pool (transductive, unsupervised). This is
documented as a caveat below.

## Caveats

* **PCA transductive fit:** the PCA(16) basis for the PLM mean pool
  is fit on the union of train and eval embedding pools (unsupervised,
  no label leakage). Train only refit is an optional later upgrade
  per memory `pca-transductive-decision-2026-05-20`.
* **anc2vec construction artefact:** the anc2vec encoder replicates
  rows per GO category, which can make
  `anc2vec_query_known_count` behave like a category bucket id under
  certain training splits. PROTEA commit `223299c` filters
  (protein, aspect) rows by genuine category membership to remove the
  effect; consumers training on this dataset inherit that fix. See
  memory `anc2vec-leakage-mechanism` for the full mechanism.
* **schema sha stability:** the canonical 8 PLM v226 lineage exports
  all carry `6d97a624b8a7`. A drift here indicates a feature added or
  removed by the producer.
* **Eval window:** the eval pair `v226-v230` is fixed
  for the whole bench-v1-K{3,5,10}-v226-lineage family so cross PLM
  and cross K comparisons see the same ground truth.

## Why this dataset exists

The dataset family is the primary research deliverable for this
thesis per the 2026-05-25 user decision (memory
`dl-postponed-2026-05-25`). The neural head DL line was postponed
because it offers no obvious win over the LightGBM v27 binary
champion on the v226 to v230 generalisation window; the curated,
exploitable multi PLM x K dataset family that PROTEA already
produces was elevated to the primary contribution. This README is
part of the FAIR packaging that makes each cell citable and
reproducible.
